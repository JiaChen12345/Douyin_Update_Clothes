# 单商品自动上架 MVP Spec

> 状态：需求草案，待用户审阅与批准。根据用户提供的第一版方案整理；不代表已经开始实现或完成上架。

## 背景

现有软件主要从供应商网站下载素材，通过浏览器填写商品并保存草稿。新的第一版需要完成一个商品从原始信息到生成内容、规则校验、人工确认及发布结果反馈的完整过程。

新能力作为独立入口提供。现有软件的运行入口、登录环境、录制流程及保存草稿行为继续按原用途工作。

## 目标

- 一次处理一个商品、一个已配置店铺，证明从商品输入到人工审核后发布的完整链路可以运行。
- 内容理解与文案生成依据来源事实；价格、库存、校验与发布执行遵循确定规则。
- 在没有外部服务凭证时可以演示完整流程，演示结果始终明确标记为模拟。
- 在真实服务配置及类目资料齐备后，同一流程可以提交真实商品，并准确反馈平台返回结果。
- 用户能够查看预览、确认发布、重新生成、取消及查询任务结果。

## 功能需求

- F1：接收单个商品的原始数据，包含商品名称、说明、成本、图片、实际规格组合及对应库存。来源链接为可选信息。同时提供明确标记的演示商品链接；已接入的来源链接可直接读取，未接入的真实链接必须提示提供原始数据，不得用演示数据冒充采集结果。
- F2：将输入转换为统一商品信息，保留来源事实和每个实际规格的对应关系。规格自身成本缺省时使用商品成本；不得擅自补齐颜色与尺码的笛卡尔积、修改库存或增加不存在的规格。重复规格及未知库存必须报错，不得用固定库存代替。
- F3：根据商品已有名称、说明及规格生成类目建议、目标用户、卖点、风格、季节和关键词，再生成标题、短描述、详情及搜索关键词。无法从来源确认的品牌、材质、认证、性能及规格不得被写成商品事实。演示内容与真实模型生成内容有可见区分；真实模式缺少内容生成服务配置时，明确报告该阶段失败。
- F4：按每个规格的实际成本和目标毛利率计算建议售价，默认目标毛利率为 45%。成本必须大于零，目标毛利率必须大于零且小于 100%。先计算达到目标所需的价格，再向上取整到整元；展示成本、建议售价、毛利额和实际毛利率。存在不同成本时展示对应规格的价格及商品价格区间。
- F5：在进入人工审核前检查标题、图片、类目、类目必填属性、售价、实际规格及库存，并扫描标题、短描述、卖点和详情中的已配置禁用词。错误阻止发布；警告可展示给用户。类目无法确认、必填资料缺失或规格有歧义时提示补充资料，不能由内容生成过程自行编造。
- F6：校验通过后展示完整商品预览，包括内容、图片、类目、属性、规格、库存、成本、售价、毛利和警告。用户确认只对当前预览版本有效；重新生成内容或修改商品后必须再次校验并确认。重新生成仅更新文案，保留来源事实及定价输入。取消后结束当前任务；发布开始后禁止重新生成、修改或取消。校验失败时允许补充信息；文案修正有次数上限，仍失败时明确列出问题并停止自动处理。
- F7：任务创建时确定演示或真实模式，后续阶段不得静默切换。只有当前版本校验通过且收到明确确认后，才能对已配置店铺执行发布。演示模式只返回模拟结果；真实模式缺少凭证、授权、平台类目映射或必要发布资料时停止并报告原因，不能自动降级为模拟成功。演示商品数据及演示生成内容不能提交到真实店铺。
- F8：展示任务标识、当前阶段、预览版本、校验结果、错误及发布结果。区别“平台已接收”“审核中”和“商品已上架”，只展示实际获得的状态；不得把平台受理或模拟结果表述为真实上架成功。发布超时或连接中断且无法确认平台结果时，标记为待核查并阻止自动重复发布。
- F9：保存商品快照、任务阶段、预览版本、确认记录及发布记录，程序重启后仍可查询。重复确认或并发确认同一任务时只允许执行一次发布；已经成功、取消或待核查的任务不得因重试确认而再次发送发布请求。重启时若发现发布尚未记录确定结果，应恢复为待核查，不能自动重新发送。

## 非功能需求

- N1：价格计算精确到分，毛利率及整元取价规则可重复验证。默认公式只考虑进货成本，不包含运费、平台费用、推广费用、退款损失或税费；预览应明确这一口径。
- N2：内容生成、采集和发布都有有限等待时间；失败给出阶段及可理解的原因。文案自动修正最多两次；不会通过自动修正改变供应商商品事实。
- N3：凭证从运行环境配置读取，不写入商品预览、任务记录、示例数据或日志；日志足以定位失败任务和阶段。
- N4：真实发布前的标题长度、类目及必填属性规则需要有明确配置和依据。初始本地规则只作为初步检查，不能声称覆盖平台的全部审核政策；演示规则不能作为真实发布的校验依据。
- N5：默认在本机运行，第一版无需提供公网部署或多人协作。外部网络调用仅用于已选择的数据源、内容生成服务和平台发布服务。
- N6：新能力可以独立安装、启动和验证；不得使现有浏览器保存草稿流程获得额外的正式发布行为。

## 不做的事

- 批量上架、自动选品、多店铺管理、价格自动调整、销量分析、广告投放和竞争对手分析。
- 自动改图、换脸、自动下架、自动补货和企业资源管理系统同步。
- 商品视频处理、复杂详情排版及多个服装类目的全面适配；首个演示类目为女装 T 恤，真实类目需按目标店铺确认。
- 第一版不承诺完成 17 网、搜款网等供应商网站的登录采集、验证码处理或反爬适配；原始数据和明确标记的演示来源先承担主流程验收。
- 构建通用浏览器控制器、改造现有桌面界面及录制回放系统。
- 自动猜测品牌、材质、认证、服装尺寸、库存、平台类目编号或必填属性。
- 无需人工确认的正式发布、未确认结果后的自动重发，以及没有真实平台响应证据的上架成功声明。

## 验收标准

- AC1（F1）：提交一份合法原始商品数据和一个演示链接，各得到一个可查询任务；演示任务显示模拟标识。提交未支持的真实链接，得到提供原始数据的提示，不生成虚构采集结果。
- AC2（F2）：输入四个实际颜色与尺码组合及不同库存，预览保持这四个组合及原库存；缺省规格成本继承商品成本，不生成其他组合。重复规格或未知库存得到具体错误。
- AC3（F3）：对未提供品牌、材质和认证的商品生成内容，输出不含新增的对应事实；标题、短描述、卖点、详情、关键词及分析结果均可查看，演示生成有明确标识。真实模式未配置内容生成服务时报告生成失败，不返回模拟内容。
- AC4（F4）：商品成本为 32 元、目标毛利率为 45% 时，建议售价为 59 元，毛利额为 27 元，实际毛利率约为 45.76%；输入不同规格成本时得到分别计算的建议售价和正确价格区间。零成本、负成本、零毛利率及大于或等于 100% 的目标毛利率均被拒绝。
- AC5（F5）：分别提交缺图、空标题、空规格、负库存、售价不高于成本、未确认类目、缺少必填属性及含已配置禁用词的商品，均得到具体校验错误，且无法执行发布；临近标题上限的合法标题显示警告。
- AC6（F6）：合法商品先停在等待确认阶段，预览包含用户需要审核的全部信息；重新生成不改变来源规格、库存和成本，旧确认失效。取消后不能发布；发布开始后重新生成、修改和取消均被拒绝。需要补充商品事实的问题保持阻断，文案修正超过两次后停止自动修正。
- AC7（F7）：未确认、校验失败或确认版本过期时，发布执行次数为零；确认合法演示任务时仅得到模拟结果。真实模式缺少必要配置时明确失败，演示数据不能进入真实发布。
- AC8（F7、F8）：外部真实服务配置齐备后，用一个经人工批准的真实商品完成一次平台提交，结果准确展示平台响应、商品标识及已知状态；若平台只返回受理信息，结果仅显示已受理，不能显示已上架。
- AC9（F8）：模拟平台拒绝、超时和不完整响应，任务分别显示明确失败或待核查状态；不能错误报告成功，待核查状态不能自动重发。
- AC10（F9）：对同一任务重复及并发确认，观察到最多一次发布调用；重启后能查询商品、审核版本及发布记录，已成功、取消或待核查任务不能重复发布。发布中断后重启，任务恢复为待核查且没有新发布调用。
- AC11（F1—F9）：完成“输入商品 → 生成内容 → 定价 → 校验 → 查看预览 → 明确确认 → 返回模拟商品标识 → 查询结果”的端到端演示，全程标识为演示，且没有真实发布调用。
- AC12（N1—N6）：预览显示毛利计算口径；内容修正及外部调用不会无限等待；日志和任务响应不含凭证；现有保存草稿流程的回归验证通过。

## 验收边界

- 演示闭环通过，只能证明本地主流程及对外调用边界有效。
- 真实平台提交单独验收。没有真实店铺授权、已确认的类目发布资料及真实平台响应时，AC8 保持未通过，不能以模拟或替身服务的测试替代。
- 用户提供的文本已经确定主流程；此草案将来源采集范围、首个类目、模拟与真实模式、取价规则、确认版本及重复发布处理具体化，均等待需求审批。
