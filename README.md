# 抖店草稿自动上款工具

从 Excel 逐行读取 17网、搜款网、淘宝或天猫商品网址，通过专用 Microsoft Edge 下载并解压素材，将主图上传到抖店，最后只保存草稿。

## 安全边界

- 程序不会点击“发布”“提交审核”或“上架”。
- 每次只处理一个商品。
- 验证码、滑块、登录失效时暂停等待人工。
- 成功后保留下载包、解压文件、日志和截图。
- 请确保你拥有素材使用权，并遵守各平台规则。

## 安装

1. 安装 Node.js 20 或更高版本以及 Microsoft Edge。
2. 在本目录执行 `npm install`。
3. 将 `config.example.json` 复制为 `config.json`；首次运行也会自动复制。
4. 双击 `setup-login.bat`，在打开的专用 Edge 中分别登录 17 网、搜款网和抖店，然后关闭浏览器。

注意：这里使用的是项目独立的 `edge-profile`，不会继承日常 Edge 的登录状态。看到抖店公开首页右上角“登录抖店”时，需要点击并完成登录，直到进入带有左侧“商品”菜单的商家后台后再关闭 Edge。

## Excel

首次运行 `run.bat` 会创建 `tasks.xlsx`。在第一张工作表的“网址”列填写商品链接，每行一个。程序自动创建并回写其他状态列。状态为“草稿成功”的行不会重复执行。

## 运行

双击 `run.bat`。浏览器会保持可见，便于人工处理验证。

每个任务的文件位于 `work` 目录：

- `downloads`：原始压缩包
- `extracted`：解压素材
- `evidence`：成功或失败截图
- `run.log`：任务日志

## 页面变化处理

平台页面会更新。通用按钮文字可在 `config.json` 的 `selectors` 中调整。若页面结构发生较大变化，查看对应任务的失败截图与日志后更新 `src/adapters` 或 `src/douyin.js`。

在正式批量运行前，先用 17 网和搜款网各一条任务完成验收。不要在未观察首条完整流程的情况下直接运行大量任务。

## Dify 工作流接入

已增加独立的 Dify 抖店接入层，保留现有 Python 步骤及弹窗关闭能力。先启动 `run-dify-bridge.bat`，
在云端 Dify 导入 `dify/douyin-workflow.yml`。无需视觉模型版可以先运行演示；
可选视觉增强模板为 `dify/douyin-vision-workflow.yml`，需要先选择支持图片的模型。
云端还需要能够访问本机后端的 HTTPS 地址，以及本机工具密钥；不能把本机 localhost 当作云端可访问地址。
详细步骤、14个原有步骤、目录设置、演示与真实模式、测试及当前未验证项见 [Dify 接入说明](dify/README.md)。

## Python 桌面版与弹窗处理

Python 抖店任务现在会在素材下载和抖店操作过程中，自动关闭可识别的广告、活动、公告和新功能弹窗。
优先点击弹窗内的“关闭”，也支持右上角的“×”或有关闭标识的图标；确认弹窗消失后继续原步骤。
登录、验证码、上传表单、商品确认和未知用途的弹窗保留给人工，不会根据截图固定位置盲点。
现有配置缺少 `autoClosePopups` 时默认启用；设置为 `false` 可关闭此功能。

双击 `run-popup-demo.bat` 可以在独立 Edge 窗口查看本地实时演示：分别关闭底部“关闭”弹窗和右上角“×”弹窗，
随后继续执行原点击步骤。演示不使用店铺登录环境，不上传或发布商品。
更新代码后通过 `run-python.bat` 运行实际抖店任务；以前已经打包的安装程序需要重新打包才会包含此改动。

新增浏览器测试可通过 `python -m unittest discover -s test_python -p test_popup_guard.py -v` 运行，
需要已安装 Microsoft Edge，测试仅使用本地页面。

项目现在同时提供了参照 waterRPA 操作方式编写的 Python 版本。它复用了同一份
`config.json`、`tasks.xlsx`、专用 Edge 登录目录和 `work` 工作目录，不影响原 Node.js 版本。

1. 首次使用双击 `setup-python.bat` 安装 Python 依赖。
2. 双击 `run-python.bat` 打开桌面控制窗口；窗口中的“上款模式”可选择单抖店或双抖店，默认双抖店。
3. 先点“登录环境”，分别登录淘宝、17网、搜款网和抖店，完成后关闭 Edge。
4. 在 GUI 选择目的上架网站，将淘宝链接粘贴到输入框，再点击“追加 T 恤网址”或“追加针织衫网址”。
5. 点击“开始处理”。任务会持久化到 `task_queue.json`，无需日常编辑 Excel。

窗口提供目的站点选择、T恤/针织衫分类追加、单/双抖店选择、开始、停止、打开工作目录及实时日志。单抖店模式只使用抖店1配置，
抖店1草稿成功即可完成任务；双抖店模式需要两个抖店均成功。验证码或安全验证出现时，
程序会暂停并等待人工在可见浏览器中完成；检测到商家后台后自动继续。Python 入口也可
直接在命令行使用：

```powershell
python douyin_automation_dual_store_v49.py --login
python douyin_automation_dual_store_v49.py
python douyin_automation_dual_store_v49.py --check
```

Python 版与原版保持相同安全边界：只识别和点击 `config.json` 中的“保存草稿”文字；
配置中一旦出现“发布”“提交审核”或“上架”，程序会主动阻断。

选择“搜款网”或“17网”时，程序不再运行内置的固定上款步骤，而是回放用户录制的操作。
GUI 的“搜款网 / 17网操作录制”区域可分别录制搜款网 T恤、搜款网针织衫、17网 T恤和
17网针织衫四套流程。选择目的站点和录制类别后点击“开始录制”，在可见 Edge 中完成示范，
最后点击“保存草稿”，再回到 GUI 点击“完成录制”。录制期间可以暂停、继续或取消；取消及
录制校验失败都不会覆盖原有文件。

录制文件保存在软件的 `recordings` 目录，并会在重新打包时随软件分发。商品标题、主图、视频、
详情图和洗水标会记录为动态任务数据，不会固定为示范商品内容。回放按控件文字和角色、页面结构、
稳定属性、坐标兜底的顺序定位。普通步骤失败后记录警告并继续，关键步骤失败则结束当前任务。
同一网站、商品类别和步骤连续失败3条任务后，日志会产生重新录制提示。录制和回放都会拦截
“发布”“确认发布”“提交审核”等正式发布操作，只允许保存草稿。

固定的“水洗标/吊牌图”保存在 `assets/wash-label.jpg`，路径由 `config.json` 的
`fixedWashLabelImage` 配置。每个商品完成 AI 生成后，程序都会将这张图上传到
“水洗标/吊牌图”区域，再继续填写发货选项、尺码表并保存草稿。

当前 Python 流程会保留抖店 AI 自动生成的原详情图，不再删除或上传下载包中的详情图。
随后固定选择“现货预售混合”“48小时”“7天内”“付款减库存”，并填写尺码表：S（150–175，
80–95）、M（150–175，95–110）、L（150–175，110–120）、XL（150–175，
120–135）。价格与库存区域会将现货库存设为 0、预售库存设为 10000，再点击“批量设置”。
“其他属性”的适用年龄固定选择“18-45周岁”；类目为“背心/吊带”时跳过年龄设置。GUI 可填写或选择本地洗水标图片路径，
默认使用 `E:\Try-onApp\wash-lable.jpg`，开始处理时保存到配置并按该路径上传。

淘宝/天猫链接会使用商品页中的浏览器插件：依次点击“手机端主图视频SKU”“批量下载”
和“单文件夹”，获取 ZIP 后复用其余抖店草稿流程。首次使用前需在专用 Edge 中登录淘宝，
并确保截图所示的素材下载插件已经启用。程序已取消 Playwright 默认的禁用扩展参数；
点击“登录环境”后可直接在这个专用 Edge 中安装一次扩展。也可在应用的“淘宝扩展目录”
中选择一个已解压、且直接包含 `manifest.json` 的扩展目录，程序启动时会显式加载它。

解压目录中如包含 MP4、MOV、AVI、MKV、WEBM 或 M4V 视频，程序会取自然排序后的
第一个视频，点击抖店“主图视频”上传区域后从本地上传；没有视频时跳过该步骤。
